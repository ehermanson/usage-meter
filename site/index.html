Questions

Why would I want this?

Most coding tools bury your rate-limit usage behind a menu or a command, and if you use more than one, you're checking each separately. Usage Meter keeps every provider's current usage and reset time in your menu bar. Bars turn yellow at 75% and red at 90%, so you can pace your work or switch tools before you hit the wall.

Which tools does it track?

Claude Code, Codex, and Gemini (via Antigravity or the Gemini CLI). For each one it shows the rate-limit windows, 5-hour and weekly, as percent used with the time until they reset.

Do I need API keys or an account?

No. Usage Meter reads the sign-ins those tools already keep on your Mac. There's nothing to paste and no account to create.

Where does my usage data go?

Nowhere else. It reads local credentials and talks only to each provider's own usage endpoint. Nothing is sent anywhere else. No analytics, no telemetry.

Does this support other tools, like Grok or Cursor?

Not right now. It's open source, though, and a new provider is mostly one small client that reads that tool's usage. If you want one added, open an issue or send a pull request on GitHub. Forks and contributions are welcome.

Is it free? What do I need?

Yes, free and open source under the MIT license. It runs on macOS 14 and later.

Download the DMG → drag to Applications → it appears in your menu bar.
